# The operations manual

One front door for how the lab works. Four pages, each self-contained:

| Page | Answers |
|---|---|
| [Estate atlas](estate-atlas.md) | What runs where, and which repo moves it |
| [Pattern catalog](pattern-catalog.md) | Which modern-ops patterns are live here, with evidence |
| [Glossary](glossary.md) | What the enterprise term maps to in this lab |
| [Runbooks](runbooks.md) | How to actually do things (mostly pointers to owning repos) |

**How this manual grows:** by harvest, not invention. Every fleet repo's README
carries a `🧭 What this repo demonstrates` section; when a new pattern lands
there, it earns a catalog row here with the same evidence link. If you read
something in the fleet that surprised you, that's a missing row — PRs welcome
(see *Make a change yourself* in the [README](../README.md)).

**Reading conventions:** pages stand alone, headings are stable (inbound links
depend on them), and every claim about the fleet links to the owning repo. If
a link and reality disagree, reality wins — file an issue.
